# Страницы vitaliybuzhan.ru (Продамус XL)

Код в HTML-блоке Продамуса (вставляется один раз):

```html
<div data-gh-page="pravila-training" data-fullbleed></div>
<script src="https://vitaliybuzhan-sudo.github.io/pages/loader.js" async></script>
```

Страница = папка `<slug>/`:
- `page.html` — порядок секций
- `sections/NN-*.html` — разметка секций
- `style.css` — стили страницы
- `page.js` — интерактив
- `img/` — картинки

Шрифты — `fonts.css` (Google Fonts), загрузчик — `loader.js`.
Правка = коммит. Сайт обновляется через 1–2 минуты, блок в Продамусе не трогаем.

Полный рабочий процесс (новые страницы, правки, ограничения) — [PROCESS.md](PROCESS.md).

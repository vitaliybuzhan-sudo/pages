# Сайты на Продамусе через GitHub — рабочий процесс

Версия 0.1 (октябрь 2026), обкатываем. После 3–5 страниц оформить в скилл.

**Суть.** Страница живёт в этом репозитории. В Продамусе — один HTML-блок с загрузчиком, его ставят один раз и больше не трогают. Любая правка = коммит, сайт обновляется через 1–2 минуты.

```
Claude Design ──экспорт──▶ Claude (конвертер) ──коммит──▶ GitHub Pages ──загрузчик──▶ Продамус XL
                                   ▲                                                        │
                                   └──────────── правки словами / скриншотом ◀──────────────┘
```

**Роли.** Виталий: дизайн, решения, загрузка картинок, создание страницы в Продамусе. Claude: конвертация, код, коммиты, проверка на живом сайте.

---

<details>
<summary><b>Процесс A. Правка существующей страницы</b> (самый частый)</summary>

1. **Виталий:** пишет, что поменять — словами или скриншотом с пометкой. Достаточно: «pravila-training, программа, неделя 3: …».
2. **Claude:** находит секцию в `<slug>/sections/`, правит, коммитит с понятным сообщением.
3. **Claude:** ждёт публикации, открывает живую страницу, проверяет десктоп и телефон.
4. **Claude:** коротко: что поменял, ссылка на коммит.

Новая картинка: Claude называет файл и путь, Виталий загружает через Upload files (ссылка ниже), Claude вставляет в разметку.
</details>

<details>
<summary><b>Процесс B. Новая страница из Claude Design</b></summary>

1. **Виталий:** в Claude Design экспортирует страницу «одним файлом» (HTML) и прикладывает в Cowork. Называет адрес страницы (slug), например `anxiety-course` → будет vitaliybuzhan.ru/anxiety-course.
2. **Claude:** прогоняет конвертер (`_tools/convert.py`), пишет `page.js` для интерактива (таймеры, переключатели, раскрытия).
3. **Claude:** проверка до публикации — сравнение с исходником пиксель в пиксель (десктоп 1280, телефон 390), проверка интерактива, проверка на «враждебной» тестовой странице (изоляция стилей).
4. **Claude:** коммитит текстовые файлы. Отдаёт архив с картинками.
5. **Виталий:** загружает картинки через Upload files.
6. **Виталий:** в Продамусе создаёт страницу с этим адресом, добавляет пустой HTML-блок, вставляет код (ниже).
7. **Claude:** проверяет живую страницу, отчитывается.
</details>

<details>
<summary><b>Процесс C. Перенос старой страницы с Продамуса</b></summary>

Как B, но исходник — HTML-код, который сейчас стоит в блоке Продамуса (или экспорт из Claude Design). После проверки Виталий заменяет старый код в блоке на код загрузчика. Пилот — pravila-training.
</details>

<details>
<summary><b>Процесс D. Большой редизайн страницы</b></summary>

Если страницу переделали в Claude Design целиком — заново через конвертер (процесс B, шаги 1–4) в ту же папку. Блок в Продамусе не меняется. Мелкие правки — всегда через процесс A, не через Claude Design: так не теряются правки, сделанные кодом.
</details>

## Код для HTML-блока Продамуса

```html
<div data-gh-page="SLUG" data-fullbleed></div>
<script src="https://vitaliybuzhan-sudo.github.io/pages/loader.js" async></script>
```
`SLUG` — имя папки страницы в репозитории. `data-fullbleed` — растянуть на всю ширину (блоки Продамуса узкие, нужен почти всегда).

<summary><b>Устройство репозитория</b></summary>

```
loader.js            загрузчик (общий для всех страниц)
fonts.css            шрифты Google Fonts (общие)
PROCESS.md           этот документ
_tools/convert.py    конвертер Claude Design → папка страницы (не публикуется)
<slug>/
  page.html          порядок секций
  sections/NN-*.html разметка секций — правки делаются здесь
  style.css          стили страницы

  img/               картинки (webp)
```

<details>
<summary><b>Правила для Claude</b></summary>

- Править точечно: одна секция — один файл. Не перезаливать страницу целиком ради мелочи.
- Сообщение коммита — что изменилось на странице, по-человечески.
- После каждого коммита — проверка на живом сайте (vitaliybuzhan.ru/<slug>), десктоп + телефон, горизонтальной прокрутки быть не должно.
- Браузер кэширует loader.js до 10 минут; перед проверкой загрузить его с `cache: 'reload'`. Секции, стили и page.js браузер перепроверяет при каждом открытии.
- Новые шрифты — добавить семейство в `fonts.css`.
- Конвертер требует python3 + Pillow, node + playwright; запускать в облачном окружении Cowork.
- Ничего не публиковать в Продамусе самому — блок ставит Виталий.
</details>

<details>
<summary><b>Ограничения и известные особенности</b></summary>

- **Картинки и другие бинарные файлы** плагин GitHub не заливает — только Виталий через Upload files. Текст (секции, стили, код) Claude коммитит сам.
- **SEO:** содержимое рисуется скриптом, поисковики видят его хуже обычного HTML (так было и в старом варианте). Если важна индексация конкретной страницы — обсудить отдельно.
- **Оплата:** кнопки ведут обычными ссылками на страницы оплаты Продамуса — это работает. Встроенные виджеты Продамуса внутрь страницы не вставляются; при необходимости ставить их отдельным блоком Продамуса под нашим.
- **Шапка/подвал Продамуса** — если включены в настройках страницы, будут видны вокруг блока.
- Репозиторий публичный (условие бесплатного GitHub Pages) — не класть сюда ничего приватного.
</details>
